# Research synthesis

Speed up the clustering; never weaken the evidence.

## Rules

1. **Quote only what's in the source.** Never paraphrase inside quotation marks, never invent a quote.
2. **Tag every point** with its participant ID (P1, P2…) so it can be traced back.
3. **Flag thin evidence.** A theme backed by a single participant is a lead to test, not a finding. Say so explicitly.
4. **Keep contradictions.** If participants disagree, show both sides instead of averaging them away.
5. **Separate observation from interpretation.** "P3 skipped the field" is an observation; "the label is unclear" is an interpretation.

## Output

For each theme:

- **Theme**: a short, neutral name
- **Evidence**: 1–3 tagged quotes or observations
- **Strength**: how many participants, and any contradicting evidence
- **So what**: the design question it raises (not yet a solution)

End with what's still unknown and what you'd test next.

## Before it goes anywhere

Remind the researcher to verify quotes against the recordings before they're used in a report or case study.
